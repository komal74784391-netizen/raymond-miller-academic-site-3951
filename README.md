# Academic Starter

A small Jekyll theme for personal academic sites.

## Pages

- `_pages/about.md` - the about page
- `_pages/cv.md` - the CV page
- `_publications/` - publications collection
- `_data/navigation.yml` - navigation entries

## Local preview

    bundle exec jekyll serve

## Theme options

Set `publications.enabled` to true to render the publications collection.

See the theme config for the badge include setting.
