Welcome to **Academic Starter**, a small Jekyll theme for personal academic sites.

This demo page ships with the theme. Replace it with your own content before
publishing. The theme supports a CV page, a publications collection and a
navigation data file.

## About the theme

The theme is intentionally minimal and easy to extend.
